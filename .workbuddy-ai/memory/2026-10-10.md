# 2026-10-10 — Travail du jour

## Responsive multi-écrans (téléphone → tablette → desktop)

L'app (`akhbar-al-kora`, actualités sportives arabes RTL, Expo Router SDK 57) était verrouillée
en portrait avec une colonne de contenu figée à 600 px. Mise en place d'un système responsive.

### Ajouts
- `src/hooks/use-responsive.ts` — breakpoints `medium: 700`, `expanded: 1080` ; expose
  `isCompact/isMedium/isExpanded`, `feedColumns` (1 ou 2), `tileColumns` (2/3/4),
  `contentMaxWidth` (640/800/960), `readingMaxWidth` (720), `showSideNav`, `heroAspectRatio`.
- `src/lib/feed-grid.ts` + `feed-grid.test.ts` — `groupIntoRows()` pour transformer une liste
  plate en lignes de N colonnes (FlashList n'utilise pas `numColumns`, on groupe manuellement).

### Modifications
- `src/components/news-ui.tsx` — `Frame` devient une coque : `SideNav` verticale persistante sur
  écrans larges (≥1080), `BottomNav` conservée en dessous. `ArticleCard` passe de la prop `hero`
  à `variant: 'hero' | 'row' | 'tile'` (nouvelle tuile pour la grille). `NewsRow` prend `variant`.
  Coque centrée `maxWidth 1360`, colonne de contenu centrée via `contentWrap` (alignItems center).
- `src/app/index.tsx` — hero déplacé dans `ListHeaderComponent`, le reste du fil en grille
  groupée (`groupIntoRows`), `key={`feed-${feedColumns}`}` pour forcer le remontage au changement
  de colonnes.
- `src/app/saved.tsx` — même grille responsive.
- `src/app/categories.tsx` — largeur de tuile calculée : `100 / tileColumns - 3` %.
- `src/app/article/[id].tsx`, `settings.tsx`, `privacy.tsx` — largeur de lecture
  `maxWidth: readingMaxWidth`, centrée (`width: '100%'` + `alignSelf: 'center'`).
- `app.json` — `orientation: "portrait"` → `"default"` (rotation autorisée sur tablette/pliable).

### Vérifications
- `tsc --noEmit` OK, `expo lint` OK, `vitest run` 57 tests OK (dont 3 nouveaux).
- Export web + captures headless Chrome via iframes (viewports exacts) dans `responsive-preview/`.
  Mesure pixel : contenu 390 → pleine largeur ; 834 → 800 px centré (17→817) ; 1440 → nav 236 +
  contenu 960 centré (358→1318). Grille 2 colonnes confirmée à 1440.

### Notes d'environnement
- `rm -rf` / `Remove-Item` passent par un shim « safe-delete » qui échoue sur certains dossiers
  (`genie-trash` : « Some operations were aborted »). Contournement : `[System.IO.Directory]::Delete($p, $true)`.
- `expo export --output-dir X` échoue si `X` existe déjà (l'étape de nettoyage passe par la corbeille) :
  exporter vers un dossier neuf.
- Chrome headless Windows a une largeur de fenêtre minimale (~500 px) : `--window-size=390` rend la
  page à 500 px. Utiliser une iframe de largeur fixe pour tester les viewports mobiles.
